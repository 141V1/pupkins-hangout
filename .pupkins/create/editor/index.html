A scene is a place in the game, laid out here and saved as scenes/<name>.scene.json. The game loads it with loadScene() from @pupkins/create/scene.

The scene editor

Click
select (again: the part inside); Shift or Ctrl adds; Alt picks the innermost
Drag
3d: orbit (left), pan (right or middle), zoom (wheel); 2d: drag to move, the yellow corner to size, the blue dot to turn, right-drag to pan
W E R
move, turn, size (3d)
F
frame the selection
C
look through the game's camera
X
snap on and off
G
grid
A
add an object
Ctrl+S
save (the game reloads with it)
Ctrl+Z / Y
undo / redo
Ctrl+D
duplicate
Ctrl+C / V
copy / paste (into another scene too)
Ctrl+G
group
Del
delete
Number fields
drag the label to scrub (Shift: faster, Alt: finer); type a sum like 2*3

Prefabs are objects to place many times (edit one, they all change) or for the game to make as it plays: world.spawn('gem'). Tags let the game find objects (world.all('coin')), and a logic name hands an object's place to the rules, as whole numbers, in the scene's logic file.

Press Esc or ? to close.
